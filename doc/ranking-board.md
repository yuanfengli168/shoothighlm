# 书海LM — LLM Ranking Board 构想

## 核心idea

书海LM 不绑定任何单一 LLM 提供商。用户可接入任意 LLM（Ollama, OpenAI, Anthropic, Google, 本地模型等）。

更进一步的差异化功能：**发布 LLM 读书能力排行榜**

## 为什么这是好idea

- 现有 LLM 排行榜测的是通用能力（MMLU, C-Eval 等）
- **没有人专门测"读书记"能力** — 长文档理解、跨章节推理、引用准确性、中文书籍理解等
- 书海LM 有天然优势：用户用不同模型读同一本书，直接产生对比数据

## Ranking 维度

| 维度 | 测什么 | 评分方式 |
|------|--------|---------|
| 长文档理解 | 10K+ token 文档的关键信息提取准确率 | 自动化测试集 |
| 跨章节推理 | 能否关联不同章节的观点 | 对比人工标注 |
| 引用准确性 | 回答是否准确引用原文，不编造 | citation accuracy % |
| 中文书籍理解 | 中文文学/学术文本的理解深度 | 中文专用测试集 |
| 思维导图质量 | 提取的实体关系是否完整合理 | 结构对比评分 |
| 闪卡生成质量 | 闪卡内容是否准确、有用 | 用户评分 |
| 信息图质量 | 生成内容是否准确、排版合理 | 用户评分 |
| 播客脚本质量 | 对话脚本是否自然、准确 | 用户评分 |
| 上下文边界 | 最大可用上下文长度 | 实际测试 |
| 速度 | tokens/sec 响应速度 | 基准测试 |

## 数据来源

1. **自动化基准测试** — 用标准测试书 + 预设问题，自动跑分
2. **众包数据** — 用户 opt-in 分享匿名使用数据
3. **社区评分** — 用户对不同模型的输出点赞/踩

## 实现路径

### Phase 1: 内置 benchmark 命令
```
shootHigh benchmark --model qwen3.5:cloud --book samples/人类简史.pdf
```
跑标准测试集，输出各维度分数

### Phase 2: 排行榜网站
- shoothighlm.com/ranking
- 定期更新，类似 Chatbot Arena 但专注文档/书籍能力

### Phase 3: 社区贡献
- 用户提交新测试书
- 用户投票评价
- 模型方提交参赛

## 商业价值

- 排行榜本身就是流量入口
- 可以成为 LLM 评测的垂直权威
- 数据可授权给模型公司
- 社区效应 → 用户粘性

## 与 Ollama Cloud 的关系

书海LM 默认推荐 Ollama Cloud（方便），但排行榜对比所有主流 LLM：
- Ollama Cloud 系列
- OpenAI GPT-5
- Anthropic Claude 4.5
- Google Gemini 3
- 本地开源模型
- 中国云模型（阿里通义、百度文心、月之暗面等）

**越多样越好 — 排行榜的价值在于全面对比**
